# UNRAVEL
## Chebet Kemboi

## Description

Unravel is a text-based adventure game.
The player can move between rooms, collect items, check their inventory and view their progress.

## Project Structure

- main.py
  - Starts the game and displays the menu.
  - Creates the player, rooms and items.
  - Handles the game loop and user input.

- player.py
  - Contains the Player class.
  - Stores the player's name, inventory and location.
  - Includes methods for moving and collecting items.

- room.py
  - Contains the Room class.
  - Stores the room name and its item.

- item.py
  - Contains the Item class.
  - Stores the item's name and weight.

## Features

- Player name and age input
- Moving between rooms
- Collecting items
- Inventory management
- Viewing game progress
